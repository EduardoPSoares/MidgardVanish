# MidgardVanish

Plugin de vanish para a staff em Paper 1.21, com pacotes NMS para esconder o jogador de verdade (lista de
jogadores, times, entidades).

## Destaques

- `/vanish`, `/vanishlist`, `/vanishtp`, `/vanishviewer`, `/vanishsettings`.
- Configurações por jogador em GUI.
- Integração com Essentials, nChat e TAB.

## Stack

Java 21 · Gradle · Paper API · NMS

## Como compilar

```bash
./gradlew build
```
